# HAMi 实验室

欢迎来到 HAMi 实验室！本系列实验将帮助你逐步学习 HAMi GPU 虚拟化技术。通过动手实践，你将掌握 HAMi 的安装配置、GPU 资源切分与共享、调度策略、进阶功能以及监控运维等核心能力。

## 前置条件

在开始实验之前，请确保你的环境满足以下要求：

- Kubernetes >= 1.18
- NVIDIA GPU 驱动 >= 440
- Helm >= 3.14
- 容器运行时：containerd 或 Docker
